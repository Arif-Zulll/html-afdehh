 Web Music Player Project

Proyek web sederhana yang menampilkan pemutar musik (*custom music player*) interaktif. Dibangun menggunakan **HTML5**, **CSS**, dan **JavaScript**, proyek ini dirancang untuk memberikan pengalaman mendengarkan musik yang mulus dan konsisten di berbagai halaman web (seperti halaman *index* dan *about*).

 Fitur Utama
* **Custom Audio Player Bar:** Desain pemutar musik kustom yang elegan dan responsif.
* **Kontrol Pemutaran:** Dilengkapi tombol *Play/Pause*, pengatur volume, dan *progress bar* interaktif.
* **Integrasi JavaScript:** Mengatur *audio source*, metadata lagu, serta pembaruan waktu pemutaran (*time updates*) secara *real-time*.
* **Navigasi Konsisten:** Fitur pemutar musik tetap terintegrasi dengan baik di halaman utama maupun halaman informasi (*about*).

 Teknologi yang Digunakan
* **HTML5** (Struktur elemen audio dan halaman)
* **CSS3** (Desain antarmuka dan *styling*)
* **JavaScript** (Logika pemutar musik dan kontrol *playback*)
